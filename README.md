# document_capture
A computer vision project that automatically detects and captures documents from a camera using Python , NumPy  and OpenCV.

# Features
Opens a live video feed when the project starts.

Detects the document from the camera.

Automatically finds the document corners.

Warps the detected document into a flat scanned-page view.

Press S to save the warped/scanned image.

Saved images are stored inside the Resources/Scanned folder.

Press Q to stop the live video and exit the program.

# Technologies Used
Python
OpenCV
NumPy
